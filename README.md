This is the Windows 2000 NVIDIA Pascal driver modded from SupraGSX's modded XP 32-bit driver (credits to him) with full hardware acceleration.

It can even work on vanilla Windows 2000, but might need Update Rollup 1 and a modded videoprt.sys.

## Known Limitations

1. It does not work with the GT 1010 or GT 1030.
2. The control panel does not work yet, but will be fixed in the next release.
